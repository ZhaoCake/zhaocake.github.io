# 关于我

我是 ZhaoCake，一名探索**计算系统如何构建**的学生——从编程语言、虚拟机，到硬件与形式化模型。

「I learn by building」·「A system is understood when you can build a smaller one.」

## 🔭 当前探索

- **编程语言与运行时**：从零构建小型解释器和虚拟机，走完 source → AST → IR → bytecode → runtime 的全链路，理解不同计算模型如何相互表示。
- **硬件与计算机体系结构**：用 Chisel 探索 RISC-V 处理器设计，研究流水线、冒险、内存系统与验证方法，借助仿真与形式化建模理解硬件行为。
- **形式化方法与系统建模**：学习 TLA+ 描述并发系统与状态转换，用可执行模型推理复杂设计。

## 🛠️ 工具栈

- 语言：Python · Scala · C/C++ · Rust（学习中）
- 硬件：Chisel · Verilog/SystemVerilog · Bluespec SystemVerilog
- 建模：TLA+
- 系统：Linux · RISC-V 生态
